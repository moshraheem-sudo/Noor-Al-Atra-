## ✨ المميزات الرئيسية للتطبيق

### 1. 🕰️ مواقيت الصلاة والأذان الذكي
- **مصدر المواقيت المعتمد:** ربط مباشر مع **مركز الكفيل للثقافة والإعلام**، مع خادم بديل فوري عبر **Aladhan (المذهب الجعفري - معهد لواء قم المقدسة)**.
- **تخصيص مؤذن لكل صلاة (متقدم):** إمكانية اختيار مؤذن مستقل لكل فريضة من الصلوات الخمس (الفجر، الظهر، العصر، المغرب، العشاء) من قائمة المؤذنين العراقيين (الحاج عامر الكاظمي، الحاج أسامة الكربلائي، المقرئ رافع العامري، أذان جامع براثا، المنشد أباذر الحلواجي) مع معاينة الصوت قبل الحفظ.
- **مركز الإشعارات والتنبيهات:**
  - بطاقة مواقيت الصلاة الثابتة في شريط الإشعارات (Android).
  - تنبيهات اقتراب الصلاة (قبل 10 دقائق و 5 دقائق) وتعقيبات ما بعد الصلاة.
  - منبه أذان دقيق يعمل بالخلفية مع أزرار إيقاف وخفض الصوت الفوري.
- **تغطية شاملة:** أكثر من 118 مدينة وقضاءً وعتبة مقدسة، مع تحديد الموقع التلقائي عبر GPS.

### 2. 🧭 بوصلة القبلة الدقيقة
- حساب زاوية السمت والمسافة المباشرة بالكيلومترات إلى الكعبة المشرفة.
- متوافقة مع مستشعرات المغناطيسية والحركة في **Android** و **iOS** (`sensors_plus 7.1.1` + `NSMotionUsageDescription`).

### 3. 📖 القرآن الكريم والتلاوات الصوتية
- المصحف الكامل (114 سورة) بالرسم العثماني المعتمد مع بيانات النزول وعدد الآيات.
- استماع مباشر لكل آية، مع قسم متكامل لكبار القراء (عبد الباسط، المنشاوي، الحصري، العفاسي، وغيرهم).
- مشغل صوتي مصغر دائم (`MiniPlayerWidget`)، حفظ موضع القراءة تلقائياً، ومتابع **ختمة القرآن الكريم** (604 صفحات).
- البحث النصي والصوتي في السور والآيات.

### 4. 🤲 العبادات والأدعية والزيارات
- **مكتبة متكاملة:** الصحيفة السجادية، المناجاة الخمس عشرة، أدعية الأيام، التعقيبات، الأدعية المشهورة (كميل، التوسل، الندبة، الافتتاح، الجوشن الكبير، إلخ)، الزيارات المأثورة (عاشوراء، وارث، أمين الله، الجامعة الكبيرة).
- **الأحكام والأذكار:** أحكام الصلاة، أحكام الصوم، أحكام الحج، أعمال الشهور، والأذكار اليومية.
- **صوتيات العبادات:** 51 تسجيلاً صوتياً للأدعية والزيارات بصوت الرادود **أحمد الفتلاوي**.
- **أدوات تفاعلية:** مسبحة السيدة الزهراء (ع)، السبحة الحرة، و**عداد الركعات والسجدات الذكي** المدعوم بمستشعر القرب في Android و iOS.

### 5. 🖼️ خلفيات العتبات والمراقد المقدسة (1,150+ خلفية 4K)
- مكتبة متجددة تلقائياً عبر مستودع [Islamic-Shrines-Wallpapers](https://github.com/moshraheem-sudo/Islamic-Shrines-Wallpapers) مقسمة إلى **9 تصنيفات** (العتبة العلوية، الحسينية، العباسية، الكاظمية، العسكرية، الرضوية، المراقد الإسلامية، عاشوراء، والعمارة الإسلامية).
- تحميل تدريجي سريع باستخدام الصور المصغّرة (`thumbnail_url`) وعرض بالدقة الأصلية (`image_url`) مع التخزين المؤقت (`Cache`).
- **التعيين والحفظ:** تعيين مباشر للشاشة الرئيسية/القفل على **Android**، وحفظ في ألبوم الصور على **iOS**.

### 6. 📅 التقويم الهجري والميلادي المتزامن
- تقويم هجري وميلادي دقيق مع عرض المناسبات الإسلامية ووفيات ومواليد المعصومين (ع) مع تحديث تلقائي للبيانات.

## 🛠️ متطلبات التشغيل والبناء

- **Flutter SDK:** `3.47.5` (أو أحدث)
- **Dart SDK:** `3.13.4` (أو أحدث)

### 🔹 البناء والتشغيل على Android
```bash
# جلب الحزم
flutter pub get

# تشغيل على جهاز متصل
flutter run

# بناء نسخة الإنتاج (Release APK)
flutter build apk --release
```

### 🔹 البناء والتشغيل على iOS (iPhone / iPad) عبر xcross أو Xcode
```bash
# فحص بيئة xcross
xcross flutter doctor

# تشغيل مباشر عبر Wi-Fi على الآيفون بدون إعادة جلب الحزم
xcross flutter run --wifi --no-pub
```
