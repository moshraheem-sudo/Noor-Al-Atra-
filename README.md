# حزمة تطبيق نور العترة - Flutter (Noor Al-Atra Flutter Edition)

نسخة كاملة ومطابقة 100% لتطبيق **نور العترة (الإصدار 5.0.0)** مبنية بالكامل باستخدام **Flutter & Dart**، محتفظة بجميع الميزات، الواجهات، الروابط البرمجية، الصوتيات، الأصول والبيانات، مع الحفاظ على الهوية البصرية الإسلامية المتميزة.

---

## 📱 محتويات ومميزات الحزمة (Features)

1. **الواجهة الرئيسية (Home Screen):**
   - بطاقة مواقيت الصلاة التفاعلية القابلة للطي والتوسيع (`CollapsibleHomePrayerCard`) مع عداد تنازلي دقيق حتى الصلاة القادمة.
   - شبكة الوصول السريع للعبادات (مواقيت الصلاة، مسبحة الزهراء، عداد الركعات، ختمة القرآن، صوتيات العبادات، القرآن الكريم).
   - قائمة أهل البيت (عليهم السلام) الأربعة عشر مع السيرة، تواريخ الولادة والشهادة والنسب.

2. **مواقيت الصلاة والقبلة (Prayer Times & Qibla):**
   - ربط كامل مع **مركز الكفيل للثقافة والإعلام** (`https://hq.alkafeel.net/Api/init/init.php?v=jsonPrayerTimes`).
   - خادم بديل فوري عبر **معهد لواء (قم المقدسة) / Aladhan** وفق طريقة الشيعة الإمامية الاثني عشرية (`method=0`).
   - جدول تفصيلي للمواقيت: الإمساك، الفجر، الشروق، الظهر، العصر، الغروب، المغرب، العشاء، منتصف الليل الشرعي.
   - بوصلة القبلة الدقيقة وحساب زاوية السمت والمسافة المباشرة إلى الكعبة المشرفة بالكيلومترات.
   - قائمة المدن العراقية والعتبات المقدسة والأقضية والمدن الإسلامية العالمية (أكثر من 118 مدينة مدمجة).

3. **القرآن الكريم والتلاوات (Holy Quran & Reciters):**
   - فهرس كامل لـ 114 سورة مع بيانات النزول (مكية / مدنية) وعدد الآيات.
   - قراءة الآيات بالنص العثماني القرآني المعتمد مستورد من Quran API.
   - الاستماع المباشر لكل آية بصوت الشيخ مشاري العفاسي عبر EveryAyah CDN.
   - قسم القراء الكامل مرتبط بخوادم MP3Quran مع تلاوات: عبد الباسط عبد الصمد، محمد صديق المنشاوي، محمود خليل الحصري، مصطفى إسماعيل، فارس عباد، سعد الغامدي، محمد رفعت، برواية حفص والمصحف المجود والمعلم.
   - مشغل صوتي مصغر (`MiniPlayerWidget`) دائم يتيح متابعة الاستماع في أي شاشة والتحكم بالتشغيل والإيقاف.
   - حفظ آخر قراءة تلقائياً ومتابعتها بنقرة واحدة.

4. **العبادات والأدعية المأثورة (Worship & Duas):**
   - أدعية أيام الأسبوع كاملة للإمام زين العابدين (ع).
   - تعقيبات الصلاة العامة والخاصة للصلوات الخمس.
   - المناجاة الخمس عشرة للإمام السجاد (ع).
   - الصحيفة السجادية الكاملة (زبور آل محمد).
   - الأدعية المشهورة (كميل، التوسل، الندبة، الافتتاح، الجوشن الكبير، العشرات، السمات، المشلول، إلخ).
   - الزيارات المأثورة (عاشوراء، وارث، الجامعة الكبيرة، أمين الله، زيارات الأيام، إلخ).
   - الأذكار اليومية وأدعية الصباح والمساء وأحكام الصوم الفقهية.
   - محرك بحث نصي فوري داخل جميع الأدعية مع إمكانية التكبير والتصغير ونسخ ومشاركة النصوص وإضافتها للمفضلة.

5. **صوتيات العبادات (Worship Audios):**
   - 51 تسجيلاً صوتياً كاملاً للأدعية والزيارات والمناجاة بصوت الرادود الحسيني **أحمد الفتلاوي** بروابط مباشرة من GitHub Raw CDN.

6. **مسبحة الزهراء (ع) والسبحة الحرة (Tasbeeh):**
   - تسبيحة السيدة فاطمة الزهراء (ع): 34 الله أكبر، 33 الحمد لله، 33 سبحان الله مع مؤشر دائري واهتزاز تفاعلي.
   - سبحة إلكترونية حرة بعداد مفتوح مع حفظ عدد التسبيحات.

7. **عداد الركعات والسجدات (Raka'at Counter):**
   - حساب الركعات لصلوات الفجر (2)، المغرب (3)، والرباعية (4) والسجدات مع إمكانية النقر الذكي للتسجيل.

8. **ختمة القرآن الكريم (Khatma Tracker):**
   - متابعة 604 صفحات مع شريط النسبة المئوية ومحدد الأجزاء ونصائح إتمام الختمة.

## 🚀 كيفية تشغيل وتعديل التطبيق على جهازك

1. انقل مجلد `flutter_noor_alatra` إلى جهازك أو افتح المشروع في محرر الأكواد المفضل لديك (VS Code أو Android Studio).
2. تأكد من تثبيت بيئة Flutter على جهازك (`flutter doctor`).
3. في موجه الأوامر (Terminal) داخل مجلد `flutter_noor_alatra`، نفذ:
   ```bash
   flutter pub get
   ```
4. لتشغيل التطبيق على الهاتف أو المحاكي:
   ```bash
   flutter run
   ```
5. لبناء ملف APK للأندرويد:
   ```bash
   flutter build apk --release
   ```
6. لبناء ملف تطبيق لنظام iOS:
   ```bash
   flutter build ipa
   ```
